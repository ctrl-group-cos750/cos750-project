# Computer Science Curricula 2023 (CS2023)

The only reference in the examination specification (`docs/spec/`):

> A. N. Kumar, R. K. Raj, S. G. Aly, M. D. Anderson, B. A. Becker, R. L. Blumenthal, E. Eaton,
> S. L. Epstein, M. Goldweber, P. Jalote, D. Lea, M. Oudshoorn, M. Pias, S. Reiser, C. Servin,
> R. Simha, T. Winters, and Q. Xiang. *Computer Science Curricula 2023*. Association for Computing
> Machinery, New York, NY, USA, 2024. ISBN 9798400710339.

The final report (version 2024-04-28), downloaded from <https://csed.acm.org/final-report/>, where
ACM publishes it section by section. The book itself is at <https://doi.org/10.1145/3664191>.

## Where to look for the project

The spec says to choose a data structure from the *Foundational Data Structures and Algorithms*
knowledge unit, plus a core algorithm that applies to it. Both are in the
**Algorithmic Foundations (AL)** knowledge area in `3.1-Body-of-Knowledge-1.pdf`, PDF pages 25–38.
